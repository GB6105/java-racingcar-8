# 문제 분석하기

이번에는 놓치는 부분이 있을 까봐 한 줄 한 줄 읽어가면서 </br>
이해하기 → 방법 생각하기 → 그에 따른 영향(긍정, 부정) 생각하기</br>
와 같은 과정을 거치기로 해보았습니다.

> “주어진 횟수 동안 n 대의 자동차는 전진 또는 멈출 수 있다.”

자동차라는 객체를 생성해서 전진과 멈춤 이라는 속성을 부여하자,</br>
그리고 그 개수와 횟수는 외부의 입력으로 받는다.</br>
객체가 많아지면 메모리나 성능에서 오류를 발생하지 않을까?

> “각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다”

자동차라는 객체 안에 이름을 데이터로 갖게 한다, 자동차가 전진하면 이 이름을 같이 출력한다.

> “자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.”

pobi,woni,jun과 같이 이름을 입력받을 수 있고 입력받은 이름을 구분지어서 자동차의 이름으로</br>
생성과 함께 객채로 만들어준다.
이름 입력에 대한 여러가지 예외 상황에 대해서 처리 해주어야한다.

> “사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야한다.”

이동 횟수를 입력받는다,입력 횟수의 범위는 어떻게 할 것인지 정해주어야한다.

> “전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다”

랜덤 숫자를 생성하고 그 값에 따라서 자동차의 상태를 변경하고 저장해준다.</br>
자동차가 여러개 생성되어있는 경우 랜덤 숫자 생성도 여러개 해주어야한다.

> “자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.”

자동차 객체마다 얼마나 이동했는지를 저장하는 값을 설정하고 이를 바탕으로 가장 높은 이동 값을 가진 객체의 이름을 출력한다.</br>
자동차 객체가 여러개면 각 값들을 다 조회하는데 시간이 오래걸리지 않을까?

> “우승자가 여러 명 일 경우 쉼표(,)를 이용하여 구분한다.”

한 명일 경우 우승자 출력, 여러 명일 경우 쉼표를 붙여서 출력한다.

> <b>그 외 다양한 예외 생각하기</b></br>
차의 입력의 없으면, 에러!</br>
차가 한 대만 입력되면? → 하나로 진행</br>
차가 수십대 입력되면? → 다 받아주어도 되나? 생각해보자!</br>
시도할 횟수 없으면, 에러!</br>
시도할 횟수 0 입력 받으면? → 0회 실행? 이라는 것은 이상하지 않을까? 잘못된 값으로 정의할 것인가? 아니면 받아줄 것 인가?</br>
시도 횟수 수만 번 → 문제가 발생하지는 않을까? 수십 혹은 수만 개의 객체의 상태를 수만 번 바꾸는 문제에 대해서 생각해보자</br>
이동한 결과에 대해서 어디에 저장할까?</br>
자동차 객체에 이동한 결과를 저장할 경우 → 추후에 우승자를 정해야 할 때 객체마다 이동 결과를 전부 불러와야하는데 문제가 생기지 않을까?</br>
이동 결과를 따로 저장하는 부분이 있는 경우 → 매번 실행할 때 마다 이동결과를 저장하는 것이 더 복잡하고 성능에 문제가 발생하지 않을까?
