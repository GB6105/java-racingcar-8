# java-racingcar-precourse


# 기능 구현 목록

### 입력 부분

| 이름 | 기능 | 세부 사항 | 입력 값 | 반환 값 |
| --- | --- | --- | --- | --- |
| inputCarNames | 자동차 이름을 입력 받는다. | 영어, 한글, 숫자 가능 / 구분자로 쉼표(,) 허용 / 최소 한 글자에서 최대 다섯 글자 | 사용자 입력 | List<String> |
|  |   |  잘못된 입력을 받으면 IllegalArgumentException를 발생 후 종료.  |  |  |
| inputTryNumber | 시도할 횟수를 입력 받는다 | 숫자 가능 / 정수 / 1 이상의 정수 | 사용자 입력 | int |
|  |  | 잘못된 입력을 받으면 IllegalArgumentException를 발생 후 종료.  |  |  |

### 자동차

| 이름 | 기능 | 세부 사항 | 입력 값 | 반환 값 |
| --- | --- | --- | --- | --- |
| moveCar | 랜덤 숫자의 결과에 따라 전진과 멈춤을 결정한다. |   | 없음 | 없음 |
|  | 전진은 이동거리를 증가시킨다. |  |  |  |
|  | 멈춤은 이동거리를 증가시키지 않는다. |  |  |  |

### 경주

| 이름 | 기능 | 세부 사항 | 입력 값 | 반환 값 |
| --- | --- | --- | --- | --- |
| raceOneRound | 경주를 1회 진행한다 | 자동차들의 전진과 멈춤을 결정한다. |  | 없음 |
|  |  |  |  |  |
| findWinner | 최종 우승자를 탐색한다. | 우승자는 단독, 공동 모두 가능하다 | List<Car> | List<String> |
|  |  |  |  |  |

### 컨트롤러

| 이름 | 기능 | 세부 사항 | 입력 값 | 반환 값 |
| --- | --- | --- | --- | --- |
| startRace | 자동차 경주를 시작한다. | 시도할 횟수 만큼 자동차들의 전진과 멈춤을 결정한다. | int tryNumber | 없음 |



### 출력 부분


| 이름 | 기능 | 세부 사항                                                                  |
| --- | --- |------------------------------------------------------------------------|
| printProgress | 차수별 실행 결과를 출력한다. | 매 실행마다 값을 출력                                                           |
|  |   | 출력 양식 - “이름 : 이동 거리(-)”                                                |
| printWinner | 우승자를 출력한다. | 출력 양식 </br>한 명일 때 - 최종 우승자 : pobi </br>공동 우승자 - 최종 우승자 : pobi , jun, … |
|  |  | 모든 실행이 완료 된 후 한 번 출력                                                   |
### 검증 부분
| 이름 | 기능 | 세부 사항 | 입력 값  | 반환 값 |
| --- | --- | --- | --- | --- |
